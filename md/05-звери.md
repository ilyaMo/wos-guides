# Направление 5: Звери (день прироста животных)

## Что копим под день зверей
- Корм, манускрипты, камни зверей, сундуки улучшения питомца — тратить только в этот день.

## Боевые звери (влияют на марши) — приоритет прокачки
Навыки активируемые: действуют 2 часа, откат 20 часов. **Активировать перед боем**: мишка, Литейка, день SvS, важные ралли.

| Зверь | Навык |
|---|---|
| **Рух** | −здоровье врага (−2% → до −5% с прокачкой). Главный боевой. |
| **Железный носорог** | +150k вместимость ралли — маст-хэв лидеру ралли |
| **Пещерный лев** | +10% атаки войск |
| **Саблезубый тигр** | +10% летальности войск |
| **Снежный барс** | +30% скорость марша, −5% летальность врага |
| Снежная обезьяна | +15k вместимость отряда (лидеру и участникам) |

Порядок: **Рух → носорог (если водим ралли) → лев/тигр → барс/обезьяна**.

## Цепочка открытия зверей
Гиена → Полярный волк → Овцебык → Тапир → **Рух** → Лось → Снежный барс → Пещерный лев (30 ур.) → Снежная обезьяна (30 ур.) → **Железный носорог** (~280 дней возраста сервера → у нас ориентировочно через ~полгода, к началу 2027).
- Экономических зверей качать **до порога открытия следующего** (15–30 ур.), не выше — они ступеньки к боевым.
- Текущий боевой приоритет: **Рух** + подтягивание цепочки до порогов.

## Экономические звери (город/развитие)
Гиена, овцебык, полярный волк и пр. — качать по остаточному принципу, материалы не размазывать.

**Не путать:** Мамонт — это босс охоты на карте (бьётся ралли, см. [06-фарм-и-энергия](06-фарм-и-энергия.md)), а не питомец.

## Прочее
- Пакеты на зверей за деньги — низкий приоритет до эры FC.
- Камни зверей в магазинах — по хорошей скидке, после боевых приоритетов (см. [магазины](магазины.md)).
- День зверей часто совмещён с фармом материалов — см. [06-фарм-и-энергия](06-фарм-и-энергия.md).
