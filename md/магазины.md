# Магазины: что покупать

## Общий принцип
**Лимитированный товар из единственного источника → первым.**
Дальше: фрагменты мификов > материалы экипировки > ускорения > остальное.
**Ресурсы (мясо/дерево/руда) не покупать нигде и никогда.**

## Лабиринт (закрывать попытки ежедневно!)
1. **Мифрил** — 1 шт./неделю, больше нигде нет → выкупать каждую неделю без пропусков.
2. Фрагменты нужных мификов (Флинт/Алонсо).
3. Ускорения — по остаточному.
- Учебники навыков НЕ покупать — падают с фарма.
- НЕ брать: ресурсы, опыт героев.

## Магазин арены (бить арену каждый день, все попытки)
- Только **фрагменты мификов** (в первую очередь свои: Алонсо/Флинт, или универсальные).
- Ускорения не брать — курс плохой.

## Магазин альянса
1. Фрагменты героев / предметы прокачки героев.
2. Ускорения (курс хороший).
3. Запас монет на **щит и телепорт к SvS** (чтобы не покупать за алмазы).
- Не брать: ресурсы, мелочь.

## Тайный магазин
1. **Персонализированные ящики с поделкой** (детали эксклюзивного оружия мификов) — топ-приоритет.
2. **Камни эссенции** (экипировка героев).
3. Камни зверей / сундуки питомца — по хорошей скидке, после 1–2.
4. Ускорения — только при скидке ~70%+ и лучше за ресурсы.
- Лоты **за ресурсы** — брать смело; **за алмазы** — только п.1–2 со скидкой.
- Платный рефреш ассортимента — никогда.

## VIP-магазин
- Только позиции из своих приоритетов (фрагменты, ускорения со скидкой 50%+), и только когда трата алмазов даёт очки (Мобилизация/день Зала).

## Ивентовые магазины (Литейка, Каньон, сезонные)
- Валюта сгорает с концом сезона → тратить под ноль до закрытия.
- Порядок: фрагменты мификов → материалы экипировки губернатора → ускорения.

## Игнорировать во всех магазинах
Ресурсы, опыт героев, фрагменты эпиков, лотерейные сундуки при наличии конкретных фрагментов рядом.
